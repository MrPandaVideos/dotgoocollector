# Security

## What this app does

Goo Collector is a local Windows utility. It:

- Scans folders you choose for `.goo` / `.gcode` files
- Copies matching files to a destination you choose

It does **not** send data over the network, collect telemetry, or require an account.

## Reporting a vulnerability

If you find a security issue, please open a GitHub issue describing the problem without including exploit details that would put other users at risk. Prefer privately contacting the repository owner when possible.

## Notes for users

- Prefer downloading `GooCollector.exe` from this repository’s default branch (or a GitHub Release if one is published).
- Windows SmartScreen may warn about an unsigned `.exe`. That is expected for a personally built app without a code-signing certificate.
- Only run the app if you trust the source of the download.
